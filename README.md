# omarchy-theme-crystal

A Kanagawa-inspired theme for [Omarchy](https://omarchy.com).

![preview](preview.png)

## Install

```bash
omarchy-theme-install https://github.com/aldochaconc/omarchy-theme-crystal
```

## Colors

Based on the [Kanagawa](https://github.com/rebelot/kanagawa.nvim) color palette.

| Role | Hex |
|------|-----|
| Background | `#1f1f28` |
| Foreground | `#dcd7ba` |
| Accent | `#7e9cd8` |
| Cursor | `#c8c093` |
