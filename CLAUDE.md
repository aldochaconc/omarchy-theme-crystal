# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

An [Omarchy](https://omarchy.com) theme package called "Crystal". Omarchy is a Linux desktop environment (Hyprland-based on Arch Linux). Themes are installed via `omarchy-theme-install <repo-url>` — there is no build step, test suite, or linter.

## Architecture

`colors.toml` is the **single source of truth**. Most app configs are auto-generated by Omarchy's template engine (`.tpl` files + `colors.toml`). This repo only ships files where the template output is insufficient:

**Auto-generated by templates** (NOT in this repo):
- Terminal emulators: kitty, alacritty, ghostty
- UI components: mako, walker, hyprland, hyprlock, chromium

**Custom overrides** (in this repo):
- `neovim.lua` — reads colors.toml at startup, maps to Kanso palette (22 keys)
- `waybar.css` — CSS vars + opacity rule + battery/indicator colors
- `swayosd.css` — imports Omarchy base + custom styling rules
- `btop.theme` — custom gradient color assignments
- `rofi.rasi` — color palette (no .tpl template exists for rofi)

**Static assets:**
- `vscode.json` — VS Code theme extension reference
- `icons.theme` — icon theme name
- `backgrounds/` — wallpaper images
- `branding/` — ASCII art, logos
- `Monaco.ttf` — bundled font

## Color System

Based on Kanso Zen (a Kanagawa variant).

| Role | Hex |
|------|-----|
| Background | `#090E13` |
| Foreground | `#dcd7ba` |
| Accent (blue) | `#8BA4B0` |
| Cursor | `#c8c093` |
| Selection BG | `#24262D` |

`colors.toml` defines: 16-color ANSI palette (color0-15), base colors (fg, bg, accent, cursor, selection), and extended Neovim palette (orange, orange2, blue2, violet2, gray3-5).

## Key Conventions

- `swayosd.css` imports a base stylesheet from Omarchy and overrides on top of it
- Font is Monaco at 10pt (rofi) or 11pt (swayosd)
- Waybar background uses 20% opacity via `@background` CSS var

## When Changing Colors

1. Update `colors.toml` — this propagates automatically to all template-generated files via `omarchy-theme-set`
2. For custom override files (waybar.css, btop.theme, rofi.rasi, swayosd.css): grep for the old hex value and update manually
3. Run `omarchy-theme-set crystal` to regenerate template outputs
